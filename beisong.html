二、易错对比（8 组 · 选择题必出）

1. 正反馈 / 负反馈
正＝放大偏差；负＝维持稳定
判据：病毒传染、人口增长、浮萍翻倍 → 正；恒温器、血糖调节 → 负
2. 自组织 / 他组织
自＝无外部指令自行有序；他＝需外部命令或设计
判据：蜂群、蚁群、鸟群 → 自；流水线 → 他
3. 开放系统 / 孤立系统
开放＝与环境交换；孤立＝不交换
判据：生物体、企业、城市 → 开放；整个宇宙 → 孤立
4. 还原论 / 整体论 / 系统论
拆开研究 / 只看整体 / 兼顾整体与部分、研究关系
判据：“拆开”→还原；“只看整体”→整体；“兼顾关系”→系统
5. 熵 / 负熵
熵＝无序度（孤立系统熵永不减少）；负熵＝从外界引入以维持有序
判据：变乱 → 熵增；靠外界维持有序 → 负熵
6. 混沌 / 随机
混沌＝确定系统因强非线性产生、非周期、短期可测长期不可测；随机＝无确定规则
判据：蝴蝶效应、洛伦兹、三体 → 混沌（≠随机）
7. 无标度网络 / 随机网络
无标度＝幂律 + 枢纽，抗随机失效、怕蓄意打枢纽；随机＝近泊松、聚类系数低、路径短
判据：幂律、互联网 → 无标度；泊松 → 随机
8. 存量 / 流量
存量＝累积量；流量＝变化率；存量对时间求导 = 流量
判据：“有多少”→存量；“变化多快”→流量

三、顺带一起考的三条

  • 小世界＝路径短 + 聚类高（社交网）；规则网络＝聚类高、路径长
  • 三种中心性：度＝邻居数；介数＝当“桥梁”的频率；接近＝到所有节点平均最短距离
  • 白箱 / 灰箱 / 黑箱：内部全知 / 部分知 / 只知输入输出
